# Cybersecurity Awareness Chatbot v2.0

A WPF GUI chatbot that educates South African citizens about cybersecurity threats including phishing, malware, password safety, and more.

## Prerequisites
- Visual Studio 2022
- .NET 8.0
- Windows OS

## How to Run
1. Clone this repository
2. Open `CybersecurityChatbot.sln` in Visual Studio 2022
3. Press F5 to build and run

## Features
- Voice greeting on startup
- ASCII art header display
- 10 cybersecurity topics with random responses
- Sentiment detection (Worried, Curious, Frustrated, Happy)
- Memory and recall (user name and favourite topic)
- Follow-up question handling ("tell me more")
- Professional dark GUI theme
- Voice goodbye on exit
